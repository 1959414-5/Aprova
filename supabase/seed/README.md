O diagnóstico inicial possui 22 questões autorais, divididas pelas cinco disciplinas do edital 2026. A origem deve permanecer identificada como questao_autoral_ia; não são itens oficiais da prova SBMG 2019.

As questões, alternativas corretas e explicações estão carregadas na tabela public.questions do Supabase Aprova. Como o repositório GitHub é público, o conteúdo com gabarito não é versionado aqui. A tabela possui RLS e privilégios de coluna: o navegador lê enunciados e alternativas, enquanto a correção é feita pela Edge Function answer-question no servidor.

Para ajustar ou ampliar o banco, faça a alteração no Supabase por migração controlada e mantenha o gabarito fora dos arquivos públicos do repositório.
